# 출장 스냅 촬영 랜딩 페이지 개발 기획서

## 1. 목적
1인 출장 스냅 사진작가의 촬영 서비스를 알리고, 방문자가 전화나 문자로 촬영 상담을 신청하게 만드는 영업용 랜딩 페이지.

## 2. 사용자
- 가족사진, 프로필 사진, 돌잔치·행사 촬영을 알아보는 사람
- 광고나 SNS 링크를 눌러 처음 들어오며, 대부분 휴대폰으로 본다

## 3. 화면 구성 (위에서 아래 순서)
1. 헤더: 왼쪽에 로고와 상호, 오른쪽에 메뉴(서비스 / 가격 / 후기 / 자주 묻는 질문)와 "상담 신청" 버튼. 스크롤해도 화면 위에 고정
2. 히어로: 대표 사진을 화면 가득 깔고, 핵심 문구, 보조 문구, "상담 신청" 버튼
3. 추천 대상: "이런 분께 추천합니다" 제목 아래 3가지
4. 서비스: 서비스 카드 3개 (사진, 서비스 이름, 한 줄 설명)
5. 진행 과정: 4단계 (상담 → 일정·장소 확정 → 촬영 → 보정본 전달)
6. 가격: 가격 카드 3개. 가운데 카드를 "추천"으로 강조
7. 후기: 고객 후기 카드 3개
8. 자주 묻는 질문: 질문 4개. 질문을 누르면 답이 펼쳐짐
9. 마지막 CTA: 짧은 문구와 "전화 상담", "문자 문의" 버튼
10. 푸터: 상호, 대표자, 전화번호, 활동 지역

## 4. 반응형
- 컴퓨터(1024px 이상): 서비스 카드, 가격 카드, 후기 카드를 각각 3개씩 가로 한 줄로
- 태블릿(768px ~ 1023px): 카드를 한 줄에 2개씩
- 휴대폰(767px 이하): 카드를 한 줄에 1개씩 세로로. 헤더 메뉴는 ☰ 버튼으로 접었다가 누르면 펼쳐지게. "상담 신청" 버튼을 화면 아래에 고정

## 5. 기능
- 헤더 메뉴를 누르면 해당 부분으로 부드럽게 이동한다
- "상담 신청" 버튼을 누르면 마지막 CTA 부분으로 이동한다
- "전화 상담" 버튼은 전화 걸기, "문자 문의" 버튼은 문자 보내기로 연결된다
- 자주 묻는 질문은 누르면 답이 펼쳐지고, 다시 누르면 접힌다

## 6. 사업 정보
- 상호: 봄날스냅
- 대표자: 한봄
- 핵심 문구: 가장 자연스러운 오늘을, 찾아가서 담아 드립니다
- 보조 문구: 대전·세종·충남 어디든, 원하는 장소로 사진작가가 직접 갑니다
- 추천 대상 1: 스튜디오의 딱딱한 사진 대신 자연스러운 가족사진을 원하는 분
- 추천 대상 2: 이력서·SNS·명함에 쓸 프로필 사진이 필요한 분
- 추천 대상 3: 돌잔치나 작은 행사를 기록해 줄 사진작가를 찾는 분
- 서비스 1: 가족 스냅 / 공원, 집 등 원하는 곳에서 찍는 자연스러운 가족사진
- 서비스 2: 프로필 촬영 / 이력서·SNS·명함용 인물 사진
- 서비스 3: 행사 스냅 / 돌잔치, 작은 결혼식, 모임 기록 촬영
- 가격 1: 베이직 / 150,000원 / 1시간 촬영, 보정본 10장
- 가격 2 (추천): 스탠다드 / 250,000원 / 2시간 촬영, 보정본 25장, 원본 전체 제공
- 가격 3: 프리미엄 / 400,000원 / 3시간 촬영, 보정본 40장, 원본 전체 제공, 액자 1개
- 후기 1: 김○○ / 가족 스냅 / 아이가 낯을 많이 가리는데도 편하게 이끌어 주셔서 웃는 사진이 많이 나왔어요.
- 후기 2: 이○○ / 프로필 촬영 / 표정과 자세를 하나하나 알려 주셔서 처음인데도 자연스럽게 찍었습니다.
- 후기 3: 박○○ / 행사 스냅 / 돌잔치 내내 중요한 순간을 놓치지 않고 담아 주셨어요.
- 자주 묻는 질문 1: 출장비가 따로 있나요? / 대전·세종은 출장비가 없고, 그 밖의 충남 지역은 거리에 따라 안내해 드립니다.
- 자주 묻는 질문 2: 보정본은 언제 받나요? / 촬영 후 7일 안에 온라인 앨범 링크로 보내 드립니다.
- 자주 묻는 질문 3: 비가 오면 어떻게 하나요? / 촬영 하루 전까지 무료로 일정을 바꿀 수 있습니다.
- 자주 묻는 질문 4: 예약금이 있나요? / 일정이 확정되면 예약금 50,000원을 받고, 나머지는 촬영 당일 결제합니다.
- 마지막 CTA 문구: 원하는 날짜와 장소를 알려 주세요. 하루 안에 답변 드립니다.
- 전화번호: 010-0000-0000
- 활동 지역: 대전 · 세종 · 충남

## 7. 제외 (넣지 않을 것)
- 로그인, 회원가입, 온라인 결제, 예약 입력 폼, 게시판, 광고, 배경 음악

## 8. 디자인
- 테마 색상: (colorswoop.com 에서 마음에 드는 팔레트의 색상 코드를 복사해 넣으세요)
- 사진이 크게 보이고 여백이 넉넉한, 따뜻하고 깔끔한 분위기
- "상담 신청" 버튼은 테마 색상으로 채워 눈에 잘 띄게
- 사진은 index.html 옆의 images 폴더에 있는 아래 파일을 그대로 사용
  - 히어로: images/hero.jpg
  - 서비스 1~3: images/service1.jpg, images/service2.jpg, images/service3.jpg
- 로고와 파비콘은 이미지 파일 없이 HTML/CSS 또는 인라인 SVG로 만든다

## 9. 기술(반드시 지킬 것)
- 결과물은 index.html 파일 하나. HTML, CSS, JavaScript를 모두 이 파일 안에 쓴다
- React, Vue, TypeScript, Vite, npm, 빌드 도구, 외부 라이브러리를 쓰지 않는다 (웹 폰트 링크는 허용)
- index.html 을 더블클릭하면 별도 설치나 서버 없이 브라우저에서 바로 열려야 한다
- 나중에 글자를 쉽게 고칠 수 있도록, 상호/문구/가격/후기/전화번호는 HTML 안에 그대로 써 넣는다
