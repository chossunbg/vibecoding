# 로또 번호 추첨기 개발 기획서

## 1. 목적
버튼을 누르면 1부터 45까지의 숫자 중 6개를 무작위로 뽑아 보여 주는, 재미로 쓰는 번호 추첨 웹페이지.

## 2. 사용자
- 로또를 사기 전에 번호를 직접 고르기 어려운 사람
- 대부분 휴대폰으로 열어서 버튼을 누르고 결과를 확인한다

## 3. 화면 구성 (위에서 아래 순서)
1. 헤더: 가운데에 로고와 서비스 이름, 그 아래 한 줄 소개
2. 뽑기 버튼: 화면 가운데에 크게 "번호 뽑기" 버튼
3. 결과: 흰색 카드 안에 번호 공 6개를 가로 한 줄로 나란히
4. 결과 아래 버튼: "결과 복사" 버튼
5. 안내 문구: "번호는 무작위로 뽑으며, 당첨과는 관계없습니다."
6. 푸터: 서비스 이름과 만든 사람

## 4. 반응형
- 컴퓨터(1024px 이상): 전체 내용을 화면 가운데 폭 480px 안에 배치
- 태블릿(768px ~ 1023px): 컴퓨터와 같은 배치, 좌우 여백만 줄인다
- 휴대폰(767px 이하): 화면 폭에 맞춰 꽉 채운다. 번호 공 6개는 한 줄에 다 들어가도록 공 크기를 줄인다

## 5. 기능
- 처음 열면 결과 자리에는 "번호 뽑기 버튼을 눌러 주세요"라고 표시하고, "결과 복사" 버튼은 누를 수 없게 흐리게 보인다
- "번호 뽑기"를 누르면 번호 6개를 뽑아 결과 카드에 보여 준다. 뽑은 뒤에는 버튼 글자가 "다시 뽑기"로 바뀌고, 다시 누르면 번호를 새로 뽑는다
- 번호 6개는 서로 겹치지 않으며, 작은 수부터 큰 수 순서로 보여 준다
- 번호 공은 왼쪽부터 하나씩 차례로 나타나는 효과를 준다
- 번호 공 색은 번호 범위에 따라 다르게 한다 (6. 데이터 참고)
- "결과 복사"를 누르면 아래 형식의 글자를 복사하고, 버튼 글자를 2초 동안 "복사했어요"로 바꾼다
  ```
  03 11 19 27 34 42
  ```

## 6. 서비스 정보·데이터
- 서비스 이름: 행운번호 뽑기
- 한 줄 소개: 고민될 때, 버튼 한 번으로 번호 6개
- 만든 사람: (본인 이름이나 별명을 넣으세요)
- 번호 범위: 1 ~ 45, 한 번에 6개
- 번호 공 색
  - 1 ~ 10: 노랑
  - 11 ~ 20: 파랑
  - 21 ~ 30: 빨강
  - 31 ~ 40: 회색
  - 41 ~ 45: 초록
- 번호 공 안 숫자는 흰색 굵은 글씨, 한 자리 수도 그대로 표시 (예: 3)

## 7. 제외 (넣지 않을 것)
- 로그인, 회원가입, 결과 저장, 당첨 번호 조회, 당첨 확률 분석, 번호 추천 이유 설명, 여러 세트 한꺼번에 뽑기
- 실제 복권 판매처의 로고, 이름, 디자인
- 광고, 배경 음악

## 8. 디자인
- 테마 색상: (#1B6F73, #E07A5F, #F2CC8F, #F4F1DE)
- 여백이 넉넉하고 깔끔한 분위기. 결과 부분은 흰색 카드 위에 올린다
- 번호 공은 동그라미, 살짝 그림자를 넣어 입체감 있게
- "번호 뽑기" 버튼은 테마 색상으로 채우고, 다른 버튼보다 크게
- 로고와 파비콘은 이미지 파일 없이 HTML/CSS 또는 인라인 SVG로 만든다

## 9. 기술(반드시 지킬 것)
- 결과물은 index.html 파일 하나. HTML, CSS, JavaScript를 모두 이 파일 안에 쓴다
- React, Vue, TypeScript, Vite, npm, 빌드 도구, 외부 라이브러리를 쓰지 않는다 (웹 폰트 링크는 허용)
- index.html 을 더블클릭하면 별도 설치나 서버 없이 브라우저에서 바로 열려야 한다
