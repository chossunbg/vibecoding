# 수박게임 (Week 8)

같은 그림 두 개를 합쳐 더 큰 그림을 만드는 모바일용 HTML 게임입니다.

- `index.html` — 과일 테마 (체리 → 수박, 11단계)
- `animal.html` — 동물 테마 (병아리 → 소, 14단계)

이미지가 HTML 안에 들어 있어서 파일 하나만 브라우저로 열면 바로 플레이할 수 있습니다.

## 플레이 방법

- 화면을 터치한 채 좌우로 움직여 위치를 정하고, 손을 떼면 떨어집니다.
- 같은 것끼리 닿으면 다음 단계로 합쳐지고 점수를 얻습니다. 연달아 합치면 콤보 배수!
- 점선 위에 2초 넘게 머물면 게임 오버.
- 📋 점수표, 🔊 소리 켜기/끄기
