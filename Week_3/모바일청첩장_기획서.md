아래 기획서대로 HTML 파일 하나로 된 모바일 청첩장 웹페이지를 만들어 줘.

# 모바일 청첩장 개발 기획서

## 1. 목적
휴대폰으로 링크를 받아 여는 결혼식 안내 페이지(모바일 청첩장)

## 2. 사용자
- 청첩장을 받은 하객. 대부분 휴대폰 세로 화면으로 본다

## 3. 화면
- 위에서 아래로 스크롤하는 세로 구성
- 휴대폰 세로 화면을 기준으로 만든다
- 컴퓨터 화면에서 열면 가운데에 휴대폰 폭으로 모아서 보이게 한다

## 4. 기능
- 스크롤을 내리면 각 부분이 부드럽게 나타난다
- 연락처의 전화 버튼을 누르면 전화 걸기로 연결된다
- 계좌번호 옆 "복사" 버튼을 누르면 계좌번호가 복사되고 "복사되었습니다"라고 표시된다
- "지도 보기" 버튼을 누르면 새 창에서 네이버 지도 검색 결과가 열린다

## 5. 참고사항
- 인적사항: 신랑 신철수(신영수, 박미숙의 장남), 신부 김영희(김영만, 이선자의 장녀)

- 장소: 대전광역시 유성구 동서대로 639, 대전 라도무스 아트센터 1층 아시시홀
- 인사말: "서로에게 가장 좋은 사람이 되기로 약속했습니다. 저희 두 사람이 새롭게 시작하는 자리에 오셔서 축복해 주시면 큰 기쁨이 되겠습니다."

## 6. 제외 (넣지 않을 것)
- 로그인, 방명록, 참석 여부 응답, 배경 음악 자동 재생, 광고
- 카카오톡 공유 버튼, 달력 저장 기능

## 7. 디자인

- 분위기: 여백이 넉넉하고 조용한 느낌

## 8. 기술
- HTML 파일 하나(index.html)을 더블클릭했을때, 별도 설치나 서버 없이 브라우저로 열려야함.
- 나중에 글자를 쉽게 고칠 수 있도록, 이름/날짜/장소/연락처/계좌번호는 HTML 안에 그대로 써 넣는다.
