# 평형 계산기 개발 기획서

## 1. 목적
㎡(제곱미터)와 평을 서로 바꿔 주는 계산기 웹페이지

## 2. 사용자
- 집을 알아보는 사람. 모델하우스나 부동산 광고에서 ㎡ 숫자를 볼 때
- 휴대폰으로 이동 중에 쓰는 경우가 많다

## 3. 화면
- 화면은 1개
- 위에서 아래로: 제목, 숫자 입력칸, 단위 전환 버튼 2개(㎡ → 평, 평 → ㎡), 결과 표시
- 휴대폰에서도 글자가 크게 보이도록

## 4. 기능
- ㎡를 입력하고 "㎡ → 평"을 누르면 평으로 표시
- 평을 입력하고 "평 → ㎡"를 누르면 ㎡로 표시
- 결과는 소수점 첫째 자리까지 반올림
- 숫자가 아닌 값을 넣으면 "숫자를 입력해 주세요"라고 표시

## 5. 기준·데이터
- 1평 = 3.3058㎡
- 결과 문구 형식: "84 ㎡ = 25.4 평"

## 6. 제외 (넣지 않을 것)
- 로그인, 저장, 광고, 지역별 시세, 다른 단위 환산

## 7. 디자인
- 테마 색상: #F1EFE7, #D9D4C7, #8C8A82, #2F2F2F
- 글자 크기: 휴대폰에서도 읽기 쉽게 크게

## 8. 기술
- HTML 파일 하나(index.html)로 만든다. 별도 설치나 서버 없이 더블클릭으로 열려야 한다.
- 이 기획서에 없는 기능은 넣지 않는다.
