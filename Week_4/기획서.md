# 맛집 소개 페이지 개발 기획서

## 1. 목적
맛집 한 곳을 소개하는 웹페이지. 처음 보는 사람도 어떤 가게인지, 무엇이 맛있는지, 어떻게 찾아가는지 한 페이지에서 알 수 있게 한다.

## 2. 사용자
- 가게를 처음 알게 된 손님
- 휴대폰, 태블릿, 컴퓨터로 모두 본다

## 3. 화면 구성 (위에서 아래 순서)
1. 헤더: 왼쪽에 로고와 가게 이름, 오른쪽에 메뉴(대표 메뉴 / 가게 소개 / 오시는 길). 스크롤해도 화면 위에 고정
2. 히어로: 가게 대표 사진을 화면 가득 깔고, 가게 이름과 한 줄 소개, "전화하기" 버튼
3. 대표 메뉴: 메뉴 카드 3개 (사진, 메뉴 이름, 가격, 한 줄 설명)
4. 가게 소개: 소개 글
5. 오시는 길: 주소, 영업시간, 휴무일, "지도 보기" 버튼
6. 푸터: 가게 이름, 주소, 전화번호

## 4. 반응형
- 컴퓨터(1024px 이상): 메뉴 카드 3개를 가로 한 줄로
- 태블릿(768px ~ 1023px): 메뉴 카드를 한 줄에 2개씩
- 휴대폰(767px 이하): 메뉴 카드를 한 줄에 1개씩 세로로. 헤더 메뉴는 ☰ 버튼으로 접었다가 누르면 펼쳐지게

## 5. 기능
- 헤더 메뉴를 누르면 해당 부분으로 부드럽게 이동한다
- "전화하기" 버튼을 누르면 전화 걸기로 연결된다
- "지도 보기" 버튼을 누르면 새 창에서 네이버 지도 검색 결과가 열린다

## 6. 가게 정보
- 가게 이름: 조씨네 밥상
- 한 줄 소개: 매일 매일 직접 정성으로 만든 밥상
- 소개 글: 조씨네 밥상은 매일 아침 맛있는 싱싱한 멸치와 다시마로 우린 맑은 국물에 김치 한 접시를 곁들여, 혼자 와도 여럿이 와도 편하게 한 끼를 드실 수 있는 동네 식당입니다.
- 대표 메뉴 1: 전골/ 9,000원 / 겉절이 상추와 함께
- 대표 메뉴 2: 수육/ 8,000원 / 그날 아침에 삶은 수육
- 대표 메뉴 3: 멸치/ 5,000원 / 바삭하게 복ㄹ은 멸치
- 주소: 대전광역시 유성구 대학로 00, 1층
- 전화번호: 042-000-0000
- 영업시간: 매일 11:00 ~ 21:00 (브레이크 타임 15:00 ~ 17:00)
- 휴무일: 매주 월요일

## 7. 제외 (넣지 않을 것)
- 로그인, 회원가입, 온라인 주문·결제, 리뷰 작성, 광고, 배경 음악

## 8. 디자인
- 테마 색상: (colorswoop.com 에서 마음에 드는 팔레트의 색상 코드를 복사해 넣으세요)
- 사진이 크게 보이고 여백이 넉넉한 구성
- 사진은 index.html 옆의 images 폴더에 있는 아래 파일을 그대로 사용
  - 히어로: images/hero.jpg
  - 대표 메뉴 1~3: images/menu1.jpg, images/menu2.jpg, images/menu3.jpg
- 로고와 파비콘은 이미지 파일 없이 HTML/CSS 또는 인라인 SVG로 만든다

## 9. 기술(반드시 지킬 것)
- 결과물은 index.html 파일 하나. HTML, CSS, JavaScript를 모두 이 파일 안에 쓴다
- React, Vue, TypeScript, Vite, npm, 빌드 도구, 외부 라이브러리를 쓰지 않는다 (웹 폰트 링크는 허용)
- index.html 을 더블클릭하면 별도 설치나 서버 없이 브라우저에서 바로 열려야 한다
- 나중에 글자를 쉽게 고칠 수 있도록, 가게 이름/메뉴/가격/영업시간/주소/전화번호는 HTML 안에 그대로 써 넣는다
